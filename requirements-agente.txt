# La consola (scripts/asesor.py) necesita UNA sola dependencia de terceros:
# httpx. La configuracion del cuanto 5 usa biblioteca estandar a proposito, de
# modo que el agente arranca sin la pila del servicio. Hay una prueba que lo
# comprueba bloqueando esos modulos: tests/arquitectura/test_puntos_de_entrada.py
#
# El servicio HTTP del agente (q5_agente/app.py) si necesita FastAPI y Pydantic,
# que ya vienen en requirements.txt.
# ------------------------------------------------------------------

-r requirements.txt

# Cliente HTTP del gateway hacia el servicio del indice. Unica dependencia
# obligatoria del cuanto 5.
#
# El rango, en vez del pin exacto que habia antes, tiene una causa concreta:
# google-genai exige httpx>=0.28.1, de modo que 'httpx==0.27.2' y el adaptador
# de Gemini no podian coexistir en el mismo entorno. Un pin que se contradice
# con otra linea del mismo archivo es peor que no tener pin.
httpx>=0.28.1,<1.0
