# Cuestionario de aceptación

Identificador del documento: **CA-SNED-01**
Se aplica **después** de las seis tareas, nunca antes.

Tres secciones. La primera sitúa al participante, la segunda mide **comprensión** y la tercera
**usabilidad percibida** con la escala estándar.

La sección 2 es propia de este proyecto y es la que más importa. La escala de usabilidad mide si
el sistema es cómodo de usar; no mide si el usuario entendió lo que vio. En un sistema que estima
un índice con consecuencia monetaria, un usuario cómodo que interpreta mal es el peor resultado
posible, y sería invisible si solo se aplicara la escala.

### Cómo se calcula

1. Ítems **impares**: restar 1 al valor marcado.
2. Ítems **pares**: restar el valor marcado a 5.
3. Sumar los diez resultados y **multiplicar por 2,5**.

Rango 0 a 100. **No es un porcentaje.** El valor de referencia habitual es 68.
